# Policy: Geographical Location & IP Anomaly

Transactions executed from a geographic location or IP subnet outside the user's primary operating region require cross-referencing with recent travel patterns or active VPN usage.

## Directive:
1. Isolated location mismatches on low-value transactions warrant step-up 2FA.
2. Location anomalies paired with new device registration and high payment amounts constitute a compound high-risk scenario.
3. Action directive: Request customer authorization or **HOLD** transaction pending location verification.
